# QA·公司主要产品知识普及 · 005 · WIFI有哪些标准？传输

## Q
WIFI有哪些标准？传输速度分别是多少？

## A
常见WIFI标准有：802.11b（11M）、802.11a/g（54M）、802.11n（300M）。现在主流的是802.11n和802.11ac，ac协议速度更快但设备要支持才行。现在买路由器建议选支持802.11ac的。
