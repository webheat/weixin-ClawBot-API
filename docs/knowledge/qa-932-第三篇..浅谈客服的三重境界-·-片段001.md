# 第三篇..浅谈客服的三重境界 · 片段001

浅谈客服的三重境界

第一重境界【接待客户，不违背店铺原则下顺利成交。客服懂的产品属性以及规范的用 语，对当前店铺活动了解透彻，向客户说明关于商品、活动、物流、售后承诺等能做到 通俗易懂的进行传递】

第二重境界【能通过交流迅速掌握客户特质，比如是豪爽型或者是磨叽型等，并有相应 的服务模式来对待，能和客户交上朋友，能灵活机动的解决客户的特殊需求并对售后维 护等方面做到维护公司形象，在让客户成为公司的口碑载体的目标实现过程中起到重要 作用，在接待客户过程中能做到以客户利益为出发点并找到公司和客户利益之间的平衡 点。】

第三重境界【对客户进行分类统计，及时发现阶段性客户性质的变化规律以及向公司提 出产品部署建议，能通过对成交订单的地址进行区域性客户特点的分析和总结，想营销 部门提出建议，能用多种对比方式对不同时间段（小时、日、周、月）客户规律进行分 析和营销总结。能及时抓住段时间内订单变化并提出库存预警等配合其他部门的一些工 作】

还是这句话，抛砖引玉，希望大家提出更多相关的经验之谈。
