# 公司主要产品知识普及 · 片段007

小常识：笔记本迅驰技术通常通常是就是带有WIFI无线局域网卡，手机的WIFI功能也指 的是就是带有WIFI局域无线网卡，WIFI现在已经成为无线局域网的统称。 Q：什么是带宽？带宽用什么单位表示？何为外网带宽和内网带宽？ A：带宽，带宽又叫频宽是指在固定的的时间可传输的资料数量，亦即在传输管道中可以 传递数据的能力。带宽的单位常以bps(bit                                    per second)。表示，即每秒可传输之位数。内网就是一个局域网或者城域网内建一个服务器 与外部的公网(即所谓的外网)进行信息交换，内网带宽指的是局域网不同设备交换传输 数据的能力，如无线局域网11M、54M等；有线局域网10M、100M、1000M等；外网带宽指 的是和外部公网的交换传输数据的能力，如ADSL的带宽1M、LAN接入10M等。形像的理解 ，如果把外网带宽比喻成一套房子的外部进水管直径的大小，内网就是房屋内部内水管 直径，水流的快慢（网速）受到外水管管径大小的制约，即内网的带宽再大外网的带宽 不足，网速依然无法跟上！ 小常识：通常ADSL或LAN接入外网宽带带宽为1- 10M，理论上无线路由器最低的11M远远超过了外网的1-10M的带宽。 Q：我是1M（2M）的ADSL宽带要用什么样的无线路由器才够用？ A：如果只考虑上网，任何的无线路由器均能满足使用，如果需要在局域网互传大数据， 建议用54M以上的无线路由器。 Q：11M、54M、108M、300M内网速度大概分别是多少呢？ A：理论上11M、54M、108M、300M内网速度用带宽除于8分别是11M传输速度为11/8=1.37 M/S；54M传输速度为54/8=6.75M/S；108M传输速度为108/8=13.5M/S，300M的内网传输为 300/8=37.5M/S，实际速度是因信号、硬件而异，不可能达到理论值的速度，实际最快速 度有理论值的一半就不错了！
