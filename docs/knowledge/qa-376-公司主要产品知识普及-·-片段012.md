# 公司主要产品知识普及 · 片段012

小知识：网卡装在电脑上都要装上驱动，当然有些在XP系统上插上去就能连接的就不需 要再装驱动了。（顾客要是说网卡不能连接，首先得问问驱动有没有装上，如果有装上 还不能上的，有可能是驱动没有装，让其重装一下试试。另外“本地网卡”一定要点禁用 ）。设置局域网，只需要在“网上邻居”“查看网络连接”中的“本地连接”或“无线连接”里 面的“属性”中的“INTERNET协议（TCI/IP）协议”中点安装“协议”就好，每台电脑都执行 这一步就可以组成局域网互相访问了。 三．如何做好产品的导购咨询： 要销售产品就必须先对产品有一定的了解，以下是各类产品的导购意向： 1．路由器 要了解顾客是想多少台电脑要共享上网，对速度有什么样的要求。如对速度要求不是很 高，仅是日常上网玩玩小游戏，则推荐11M的无线路由器或AP；如果对速度要求比较高的 ，则推荐54M或108M及以上。一般家用的无线路由器，均带有4个LAN接口，即可接四台有 线电脑，如要增加有线接入的数量，则增加一台或多台交换机即可。一台无线路由器要 无线上网的话理论上可以接入254台电脑，基本能够满足家用和办公的日常使用要求。 2．网卡 了解顾客所用的笔记本是否带无线网卡，如果没带，而且顾客有DIY能力的，则可推荐M INI PCI接口的无线网卡，但首先要了解顾客的机型是全高还是半高的，因为全高型的机子全 高和半高网卡都可以使用，但是半高型的机子就只能用半高的网卡。全高网卡的规格是 6*5CM；半高网卡的规格是6*4.5CM。（半高和全高除了尺寸规格上的区别外，相同的芯 片的半高和全高卡性能是无差别的）另外还需要了解顾客用的是什么牌子的本本，如是 IBM的则首先要告知对方，非原装网卡要在MS DOS下执行1802破解后才可装上非原装的网卡；如要即插即用的，则推荐PCMICA接口的网 卡或USB接口网卡；顾客如果台式机也不想布线，则推荐PCI接口或USB接口的无线网卡。
