# 公司主要产品知识普及 · 片段008

 Q：什么内网速度？ A：内网速度指不通过互联网，只是在局域网内部不同的电脑之间互传拷贝数据的传输速 度。 小常识：无线路由器108M，同样连接这两台路由器的ＱＱ互传数据，速度和理论理值差 别更远，其原因此数据传输不属于内网，因此速度是由外网决定的。 Q：内网LAN有线连接带宽分别是多少呢？ A：内网LAN有线连接速度分别有10M（过时的产品，比较少见）、100M（常见普及型）、 1000M（比较新的产品，未普及），传输速度分别为10/8=1.25M/S、100/8=12.5M/S、10 00/8=125M/S。 Q：什么是频道？通常的无线路由器有几个频道？ A：又叫信道，是传输广播、电视、通信信号时使用的频率范围。无线路由器工作频率是 2.4GHZ，但其工作频道有12个，分别为1频道2.412GHZ、2频道为2.417GHZ，以此类推， 每个频道加0.005GHZ，12频道为2.467GHZ，多个频道能防止不同的路由在一起使用互相 干扰。 Q：家用路由器主要有哪些品牌？ A：主要有ISCO      LINKSYS思科、NETGEAR美国网件、BUFALLO巴比禄、ASUS华硕、D- LINK友讯、华为3COM、TP- LINK普联、MECURY水星、TENGDA腾达、ALPHA阿尔法、DWNET中怡数宽等品牌。 Q：什么是Bit、Byte、KB、MB、GB、TB？ A：bit-比特； byte-拜特（字节）； k-千；KB-千字节；Kb-千比特；MB-兆字节；Mb- 兆比特；GB-千兆字节、Gb- 千兆比特、TB/Tb/PB/Pb……1字节＝8比特；1024KB=1MB，他们的换算系数均为1024以此类 推，用于表示信息的数量的单位。 Q：无线网卡分为几种？网卡的导购有哪些注意事项？
