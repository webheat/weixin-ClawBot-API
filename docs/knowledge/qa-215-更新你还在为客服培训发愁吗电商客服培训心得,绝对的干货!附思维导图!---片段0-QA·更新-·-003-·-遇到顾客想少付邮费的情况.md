# QA·更新 · 003 · 遇到顾客想少付邮费的情况

## Q
遇到顾客想少付邮费的情况，客服怎么处理？

## A
我们有一条规则：真正站在顾客角度考虑问题的客服会得到奖励。比如顾客支付宝差5块钱，客服丸子主动想了个办法，说反正发江浙沪的件多，顺风件成本其实摊得开，建议公司免了这5块。顾客体验好了，给了超长好评，收益远超5块钱。这种灵活为顾客着想的做法，我们当场给了现金奖励。
