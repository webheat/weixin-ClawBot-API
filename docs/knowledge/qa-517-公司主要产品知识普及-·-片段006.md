# 公司主要产品知识普及 · 片段006

 Q：什么是路由器的固件和第三方固件？ A：所谓固件(Firmware)就是写入EROM或EPROM(可编程只读存储器)中的程序，通俗的理 解就是“固化的软件”，简单的理解就是路由器的操作系统；每个路由器厂家所出厂时为 路由器装的“操作系统”——固件即官方固件，由第三方编写通用的路由“操作系统”即第三 方固件，第三方固件常见的有DDWRT、OPENWRT、TOMATO等。 Q：路由器刷新DDWRT固件后主要有哪些功能？ A：             1．支持发射功率调节、客户端、网桥、中继功能；            2． 支持VPN的PPTP客户端和PPTP服务器端设置，可以提供VPN接入；                 3． 可以通过设置，轻松管理各种网络服务，例如彻底封杀BT，电驴，迅雷等；4． 支持UPNP和端口映射功能；5．            可以轻松实现无线路由器的定时开关；6． 可以利用Q0S、限速、限连接数等设置来优化宽带；7． 支持多国语言，可以搭配802.1X协议，EAP（Extensible AuthenticationProtocol，可扩展认证协议）来增加网络认证应用；             8． 支持IPv6、SNMP协议，SSH服务等；9．支持花生壳的DDNS； Q：DDWRT和TOMATO蕃茄的区别及性能上的差别？ A：同样均为热门的路由器第三方固件，DDWRT相比TOMATO番茄功能更强大，TOMATO蕃茄 固件更小，长期运行比DDWRT更稳定，但TOMATO有些功能相比的缺失，如无中继功能就是 一个比较大的遗憾。其它的功能和DDWRT相差不大。 Q：什么是天线的增益和DBI？ A：增益是天线的主要指标之一，它是方向系数与效率的乘积，是天线辐射或接收电波大 小的表现。

增益大小的选择取决于系统设计对电波覆盖区域的要求，简单地说，在同等 条件下，增益越高，电波传播的距离越远，一般基地台天线采用高增益天线，移动台天 线采用低增益天线。增益的单位为DBI，即表示接收信号或发身信号的强弱，数值越高， 就越强，是一个相对值，有些人通俗的叫法，也叫分贝。 Q：无线路由可以发射多远的距离？ A：一般家用无线路由器发射距离室内15米- 50米，室外无遮挡在150米左右，通常在一套房子里均可以很方便的使用无线路由器，信 号同时可以覆盖放路由器的那一层上下两层、左右邻居的部份区域。 Q：什么是局域网和广域网？ A：局域网是在一个较小的区域内的网络，通常是指一幢楼内或一个单位内。
　广域网又称远程网，它的作用范围通常为几十到几千公里，甚至整个世界。比如因特 网已经把180多个国家和地区的几千万台计算机连接起来，形成了一个遍布全世界的广域 网。 Q：什么是WIFI？包括哪些标准？ A：全称Wireless Fidelity，是无线局域网的统称，早期指IEEE802.11b标准，它的最大优点就是传输速度 较高，可以达到11Mbps，另外它的有效距离也很长，同时也与已有的各种802.11 DSSS设备兼容。包括IEEE802.11A、802.11B、802.11G、802.11N几个标准，他们的传输 速率分别为IEEE802.11A   54M、802.11B   11M、IEEE802.11G    54M/108M、802.11N 300M，802.11B、802.11G、802.11N工作频率2.4GHZ，三种标准完全相兼容，与802.11A 不兼容，工作频率为5GHZ。
