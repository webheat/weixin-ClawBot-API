# 公司主要产品知识普及 · 片段002

C类IP地址：一个C类IP地址由3字节的网络地址和1字节的主机地 址组成，网络地址的最高位必须是“110”。范围从192.0.0.0到223.255.255.255，C类网 络可达209万余个，每个网络能容纳254个主机。D类地址用于多点广播（Multicast）：
 D类IP地址第一个字节以“lll0”开始，它是一个专门保留的地址。它并不指向特定的网 络，目前这一类地址被用在多点广播（Multicast）中。多点广播地址用来一次寻址一组 计算机，它标识共享同一协议的一组计算机。 E类IP地址：以“llll0”开始，为将来使用保留， 全零（“0.0.0.0”）地址对应于当前主机；全“1”的IP地址（“255.255.255.255”）是当前 子网的广播地址。 Q：什么是自动获取IP和指定IP？ A：自动获取IP可以理解为“门牌号”（IP）为上一级管理部门（DHCP）分发下来，也称为 动态IP，这个“门牌号”随时都有可能会不一样；指定IP相当于不是由上一级管理部门分 发，而是自己指定要“门牌号”（IP），也称静态IP，这个“门牌号”只要你不去更改，那 永远不会改变。 Q：什么是IP受限制和IP冲突？ A：IP受限限相当于得不到上一级管理部门分发的“门牌号”（IP），即分配不到IP；IP冲 突，指在同一个局域网内，两台电脑分配到同样的“门牌号”（IP）导致无法正常上网， 此时计算机提示IP冲突，解决的方法可以用指定IP，通常大型的局域网均采取指定IP以 防止IP冲突。 Q：什么是DHCP？ A：DHCP         是动态主机配置协议（Dynamic          Host          Configure Protocol）的缩写，DHCP服务器可以让管理员集中指派和指定全局的和子网特有的TCP/ IP                                                                参数（含IP 地址、网关、DNS服务器等）供整个网络使用，通俗理解DHCP服务器相当于分发“门牌号 ”的主管部门，DHCP就是分发门牌号的权力。
