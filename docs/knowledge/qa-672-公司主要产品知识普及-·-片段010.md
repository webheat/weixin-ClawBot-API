# 公司主要产品知识普及 · 片段010

 A：第一，先确认所要更换天线的设备是否可拆卸，再确定接口是SMA还是TNC接口；第二 ，确定顾客是要全向天线还是要定向天线，通常远距离两点对连以推荐定向天线，近距 离室内推荐全向天线；第三，在买家寻问效果或下单之前，永远记得告诉买家“天线使用 效果很难量化，受到环境及外界干扰等多方面的影响，均无法保证确切的效果，因环境 而异”提前打预防针，防止因为使用效果的差异带来的争议； Q：什么是全向天线和定向天线？ A：全向天线是把垂直上下方向的能量向水平方向360°辐射，从而获得水平方向的增益（ 见下图）。由此看出全向天线的辐射图像是一个面包圈，面包圈垂直方向越薄，水平方 向越大。 推荐笔记本用无线网卡导购中有哪些注意事项？ A：首先确认买家是需要内置网卡还是外置网卡；其次，如要内置网卡要让买家确认插槽 是MIMI                                                PCI（1代插槽）还是PCI- E（二代），和是否已经有预埋内置天线；第三，如要外置网卡则推荐USB或PCM接口，U SB接口不存在兼容性问题，PCM则有P口（1代）、T口、E口（2代），局域网卡很少有2代 接口，如要是2代PCM接口则不能用外置的PCM网卡，不确定时，让顾客自行确定接口后再 购买。 小常识：通常迅驰以上的CPU笔记本均有预留MINI PCI插槽和内置天线；双核或者945及以上芯片组均有预留PCI- E内置插槽和内置天线，外置PCM接口一般都是二代接口中。 Q：什么是BT、电驴、迅雷？ A：三者都当前比较流行的P2P多线程下载软件，使用P2P软件对带宽的资源占用非常严重 ，通常1M的ADSL宽带其中一台用这些软件下载，另一台上网打开网页都非常缓慢。 Q：什么是卫星共享？

AP如何应用在卫星共享中？ A：指卫星电视收看中的解密是共享盒通过网线接口连接到路由器从互联网接收解密信号 ，达到收看一些加密的卫星信号，通常CV12就是指卫星共享盒。AP应用在卫星共享中， 典型的应用就是AP的客户端功能，所有的具备客户端功能的AP均可和共享盒配合，简单 的理解就是用AP代替网线，免去布线的麻烦。中国电信的IPTV AP的应用原理是一样的，要记住，并非AP可以接收卫星信号。 Q：无线路由器有没有辐射及对人体有害？加大天线的增益是否会加大辐射呢？ A：家用无线路由器通常发射功率不超过50MW，而我们的手机最大发射功能达到1－2W， 相比手机，无线的辐射是微乎其乎的，无线辐射无处不在，我们每天都被各种电波包围 着，电磁辐射只有在能量达到一定数值时，才会成为电磁污染，才会对人体产生伤害， 小量辐射人体自身的调节能力完全可以抵消其影响，无需担心对人体会造成的危害，目 前亦无相关的医学研究证明无线路由器辐射对人体有害。加大天线的增益只是增加电磁 波的传输效率，并不增加电磁波的发射功率，因些不存在加大天线增会增强辐射！ Q：什么方法可以改善增强无线路由器信号？ A：首先，最简单不花成本方式，调整无线路由器的安装位置，以更好的完成信号覆盖； 其次，根据环境选择合适的增益天线，或天线放大器；第三，增加AP作为接入点或中继 功能增强信号的覆盖范围；三种方安根据实际情况灵活推荐使用。
