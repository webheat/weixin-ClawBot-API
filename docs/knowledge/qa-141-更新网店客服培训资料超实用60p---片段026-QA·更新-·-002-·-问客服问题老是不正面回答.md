# QA·更新 · 002 · 问客服问题老是不正面回答

## Q
问客服问题老是不正面回答，顾左右而言他怎么办？

## A
买家问掉不掉色，客服只说“质量没问题”；问什么时候到，只说“我今天发”。这不叫回答，这叫敷衍！正确做法：要比买家问的更详细。比如：“这款衣服不会掉色的请您放心哦，我今天准时为您发货走快递，正常2天到，希望您喜欢呀！”详细到让买家彻底安心才到位。
