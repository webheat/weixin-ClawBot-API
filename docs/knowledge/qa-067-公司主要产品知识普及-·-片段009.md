# 公司主要产品知识普及 · 片段009

 A：一从连接形式来分有广域网和局域网，广域网目前主要有中国移动的GPRS/EGDE和中 国联通的CDMA以及最近出出来的3G网络的TSCDMA，局域网的主要是符合IEEE802.11ABGN 无线通讯标准的网卡； 二、从接口形式可分内置网卡和外置网卡，外置网卡的主要的PCMICA、PCMICA EXPRESS（二代接口，有E口和T口两种）、USB三种接口，内置无线网卡主要有PCI（台式 机专用）、MiniPci、PCI-E（笔记本专用）； 三、从传输速率来分，局域网理论传输速率主要有11M、54M、108M等带宽，广域网理论 上速度               edge理论最高速度473.6k               实际平均速度在100- 150k左右，GPRS理论上是56K，实际平均速度在30K左右，cdma的理论最高速度在153.6k ，实际平均速度在110k左右。 Q：无线路由器的导购有哪些注意事项？ A：首先要了解买家的使用环境，避免因为无法使用无法使用路由器的环境而误买，如有 此买家在一幢楼安装无线路由器，隔200米远的另一处要接收，并且中间有另一幢房子挡 住，根本无法使用无线路由器实现共享上网，请参照“无线路由可以发射多远的距离？” QA问答做判断；
    其次，要了解买家目前拥有的设备情况，如是否已经有无线网卡，有路由器没有无线 网卡那也是用不上无线的功能，如没有配套的无线网卡，则配套推荐；
    第三，了解买家是需要一款普通的无线路由器还是需要一款多功能路由器，如可以刷 DDWRT当中继使用，根据其需要推荐；
    第四，了解的预算（想花多少钱），根据顾客的预算推荐相应的路由器，结合我们的 库存情况、主推型号及买家的预算进行有针对性的推荐； Q：天线的导购有哪些注意事项？
