# QA·公司主要产品知识普及 · 001 · 带宽是什么？外网带宽和内

## Q
带宽是什么？外网带宽和内网带宽有什么区别？

## A
带宽是指在固定时间内可传输的资料数量，单位是bps（每秒位数）。内网带宽指局域网内设备之间交换数据的能力，如54M、300M；外网带宽指和外部公网交换数据的能力，如ADSL的1M、10M。可以理解为：外网带宽是进水管，内网带宽是屋内水管，水流快慢（网速）受外网带宽制约。
