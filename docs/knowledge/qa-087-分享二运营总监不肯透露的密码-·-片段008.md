# 分享二:运营总监不肯透露的密码 · 片段008

1、天天特价：该活动主要是给消费者提供一些物美价廉且性价比很高的商品，商品在天 天特价平台销售的价格一般是正常零售价的一半，基本是按照成本价来销售。由于酷奇 奇的创意礼物主要是给顾客们塑造一种高贵精美的形象地位，因此不适合在此处推广新 商品，而是把一些节日属性强，囤货数量比较大且短期之内无法销售完的商品作为该活 动的对象。如花火夜灯，由于今年受到新春和情人节的重叠，销量情况一般。由于该商 品节日属性比较强，在短期之内是无法大量销售出去，所以可以通过天天特价把大量囤 货的花火夜灯以接近成本价清理出去，避免承担商品累计折旧费，增加酷奇奇的信誉度 ，加快流动资金周转速度，更是为酷奇奇引进更多新的顾客。

2、试用中心：对于价格偏高的新商品的上架，消费者在购买时尤其谨慎，一来是价格的 敏感度高，二来则是不清楚商品的实际使用效果。商家除了运用直通车竞价软件进行推 广，可以通过参加淘宝试用中心进行口碑营销，让淘宝VIP会员来免费试用新商品，使用 过后VIP会员需要把使用时的商品效果和感想体会详细的写出来并展示在试用中心给其他 的消费者观看，这不仅真实的展示商品的实际性使用效果，更是大大的提高消费者的购 买信任度，为打造热销商品奠基坚实的基础。如阿凡达花火夜灯，价格针对其他的创意 礼物稍微偏高，酷奇奇可以在试用中心免费提高一定数量的阿凡达花火夜灯给淘宝VIP会 员试用，整个交易和使用体会流程由淘宝平台的管理员监管，淘宝VIP会员在试用过后若 还想再购买的话还有会员优惠价。通过淘宝VIP会员的口碑宣传更好的让其他的消费者了 解到阿凡达花火夜灯的优势特性所在。

3、积分购物：淘宝平台开通一项积分购物的渠道页面，消费者在淘宝平台购买商品的时 候会获得金币积分的奖励，积分越多说明该顾客的购买等级越高，商家如果很好的使用 积分购物这个服务，就能有更多的机会挽留消费者以后多次性在该平台消费，使其成为 店铺的忠诚顾客。商城可以通过免费提供一些比较低价的商品为作为积分换购的奖励， 吸引那些积分换购的消费者，让消费者了解酷奇奇的商品和服务。另外酷奇奇适当的调 整商品搭配可以使得这些积分换购者在换购商品的同时，还会再另外捆绑购买其他一些 商品。如酷奇奇选择家务骰子和蜡烛灯这些低成本的商品作为积分换购活动的商品，在 有效的打造商品的人气热销度的同时，也拉动其他商品的整体销量，大大增加酷奇奇成 交转换率和单件客单价。
