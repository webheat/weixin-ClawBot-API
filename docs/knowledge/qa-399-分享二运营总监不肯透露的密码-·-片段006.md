# 分享二:运营总监不肯透露的密码 · 片段006

2、商品被访数据：量子统计数据软件每个星期都会对店铺热销商品进行销售排行，并详 细展示了各个热销商品的关注度、浏览量、平均访问时间和跳失率。关注度、流量和销 售量很高的商品表明它在市场上已经得到很大关注，占领了一定的市场地位，消费者都 很认同并乐意来商城购买它，因此这些热销的商品平均访问时间很高并且跳失率很低， 裙带的效果使得我们可以减轻该商品的广告投入费用，我们可以利用更多的资金去推广 和打造其他热销商品。对于长期在推广下但平均访问时间和跳失率仍处于低下的商品， 有可能是该商品的文案描述或者图片拍摄不完善，如果经过调整和完善还不见效的话， 这个可以说明了该商品不能很好的迎合消费者的需求，市场效果不好。对此商城需要对 该商品进行最后的清仓并下架，直接转换其他商品。 如果一些商品在没有投入任何的广告费，销售量一般但浏览量和关注度这些数据很不错 的情况下，这说明它在市场极具可能有成为热销商品的潜质，商城可以针对不同的时期 下，在适当的调整价格、完善商品文案描述和图片的基础上加大广告费用投入或者参加 促销活动进行推广，使得该商品在浏览量和关注度等各方面得到更大的提升，从而打造 成为店铺中一款热销商品。

3、首页被访数据：商城的主页、商品页和分类页面入口的流量都各不相同的。商城可以 在这3大入口进行流量统计，区分哪些页面入口是优质还是低质。通过2月份的首页被访 数据分析可以知道：商品页入口流量是最大。大多数消费者都是通过淘宝搜索引擎来进 入商城网站的商品页，因此我们必须要在商品页做好功夫，如设计精美的商品广告图和 相关性商品专栏推荐等。很好的引导到访的消费者去知道和了解商城更多的商品，并购 买到他们真正需要的礼物。分类页面入口则是取决于店铺内部商品分类结构，要很好的 了解消费者来购买创意礼物的选择要求和赠送对象等因素，从而针对商品的属性、功能 和用途来细分，让消费者以最短的时间购买到最满意的礼物。主页入口的流量不仅是图 片装修结构的影响，更是取决与整个店铺的经营管理。这个需要长期的时间来完善和调 整，让更多的消费者认同商城的工作能力和服务理念，这样越来越多的消费者就会把商 城收藏在自己电脑的文件夹，只要一想到购买创意礼物，他们就会直接点击打开商城的 网站。

4、店铺访问数据：目前为止访问商城的广东省消费者有18%左右，江浙沪一带将近有31 %，这说明我们在这一带范围我们拥有一定的优势，因此我们需要很好的巩固这里的地位 ，我们通过结合访客网购兴趣分析报表适当的进行促销活动。利用一定的利润返点和优 惠的形式稳固和加强广东省和江浙沪一带消费者群体。

5、直通车数据：直通车是淘宝商家引进流量的主要推广商品的软件。商城在打造热销商 品可以根据市场的反映，结合直通车关键词报表排名和柴门牌淘宝关键词优化工具来选 择哪款商品和关键词，并决定选择哪个层次的关键词竞价。在使用直通车软件后，需要 每天对通知车的点击效果趋势图和报表进行分析，如果浏览量、收藏指数和成交指数这 3大方面都取得良好的效果的话，并且隔日的对比都得到很大的提升的话，可以继续保持 或者加大力度进行推广。相反如果平均的点击效果并没有比以前得到提升，可以减轻一 下推广力度，分析问题出现的所在，避免盲目的耗资推广。
