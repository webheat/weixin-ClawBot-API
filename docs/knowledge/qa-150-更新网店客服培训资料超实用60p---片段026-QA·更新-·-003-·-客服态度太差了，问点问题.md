# QA·更新 · 003 · 客服态度太差了，问点问题

## Q
客服态度太差了，问点问题就说“晕”，买东西有问题还说“概不退换随便投诉”，能举报吗？

## A
说“晕”非常不礼貌，要把“晕”换成“不好意思”，“恩”换成“好的/是的”。遇到退货要求就说“概不退换”更会激怒买家。正确话术：“对不起发货时没仔细检查，问题不大的话我退您部分货款可以吗？实在接受不了我同意退货，希望您理解”。和气才能生财，别跟钱过不去。
