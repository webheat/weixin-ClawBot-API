# QA·客服专用快捷术语 · 001 · 收到的东西有瑕疵怎么办？

## Q
收到的东西有瑕疵怎么办？

## A
您好，如果收到的商品有瑕疵，我们有三种处理方式：①您认为瑕疵可以接受，我们为您补偿差价；②您认为瑕疵不可以接受，我们会重新为您发货；③您认为瑕疵不可以接受，我们可以为您退款。具体是否需要退回商品，我们会根据照片情况通知您。给您添麻烦了，请接受我们的歉意～
