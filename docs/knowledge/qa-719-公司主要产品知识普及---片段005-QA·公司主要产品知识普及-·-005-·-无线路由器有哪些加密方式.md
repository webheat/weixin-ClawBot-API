# QA·公司主要产品知识普及 · 005 · 无线路由器有哪些加密方式

## Q
无线路由器有哪些加密方式？

## A
主要有四种：一是设置网络密钥（WEP/WPA模式，64位或128位加密），输入10个或26个字符作为密码；二是禁用SSID广播，让别人搜不到你的网络名；三是禁用DHCP，不让路由器自动分配IP；四是启用MAC/IP地址过滤，只允许列表中的设备接入。
