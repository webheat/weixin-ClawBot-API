# 第十篇..一个年薪20万客服的思考-我如何能不一样 · 片段004

你 试过给客户写信吗？当然了，大家都说俺们发货时候里面放信的，也有很多人做，现在 也被做烂了，看见信已经见怪不怪了，世界上本来有很多好方法，人用的多了 好方法用成了最差的方法，这个方式我本不打算说的，但是还是讲了，我估计很少有人 能坚持的，我寄给老客户的信是纯手工的，自己每天按写好的内容抄几篇，虽 然内容固定，但是给每个顾客写的时候我可是一笔一划，透着无限的真情实感啊。（说 的有些假），后来鼓动家里人没有事情的时候也帮我写，甚至后来找一些退休 的人，1块钱1封的写（都是我自己出的钱），然后在重要的节日用平信发过去，邮资8毛 。一封信算下来要2块多，几千个就是上万块，这可跟包裹里打印的信差 别大了去了，专程邮寄，真心实意，真情实感，咱玩的是复古和微创新，嘿嘿，请其他 客服同志别骂我，为啥都是你自己出钱啊？其实咱干什么事情得算投入产出 比，你如果投入1万块,他们能给你带来10万的收入你愿意不愿意？这就是我愿意的原因 啊！当然公司愿意支付是更好的哦！

大牛，看到这里你知道为啥你第一个月销售额10万，我5万，第二个月你15万，我10万， 到现在我都能做100多万，你一直30万徘徊吗？原因只有一个，你是做销售的，我是做个 人品牌的，任何客服都可以成为自媒体啊，还能成为带销售性质的自媒体，哇哈哈哈……

这就是我想做一个与众不同的客服的思考和实践，致我献给客服岁月的青春……..
