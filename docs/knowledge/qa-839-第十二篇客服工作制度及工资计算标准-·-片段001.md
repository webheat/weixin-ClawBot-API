# 第十二篇:客服工作制度及工资计算标准 · 片段001

客服工作制度及工资计算标准

为规范工作职责，规避异地办公造成的问题，现实行以下客服工作制度：

1、严格遵守作息时间，客服人员上下班,第一时间给给店长旺旺留言报到。

2、对客户要热情，友好，永远比客户多说一句话（哪怕一个表情），保证第一时间回复 客户。

3、客户给予中差评，及时与客户沟通解决，让客户更正为好评。

4、客户议价时，需要2轮以上劝导

5、积极维护西娅利益，有损西娅利益者，西娅酌情考虑予以处罚。

6、禁止向商城客户使用QQ发送其他店铺网址或者银行帐号信息

7、严禁他人代替上岗

8、下班时，如遇客户正在咨询，接待完客户后方可下线。

9、客服仅有查看浏览淘宝后台权限，除修改邮费和价格外，不得使用其他功能。

10、客服之间工作性交流需使用本店旺旺交流，不得使用其他工具。

注：以上条款西娅包包馆保留最终解释权和补充权利！
