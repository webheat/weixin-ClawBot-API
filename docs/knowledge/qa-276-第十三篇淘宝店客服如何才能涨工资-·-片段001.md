# 第十三篇:淘宝店客服如何才能涨工资 · 片段001

淘宝店客服如何才能涨工资?

本来想把标题写成"如何才能提高客服自身的水平",标题在派代上的高手看来,感觉很土 ,但对于那些客服来说或许是很吸引,看完帖子,我想高手们也会觉得有那么一点的道理! 虽然语言表达的很白话.的确写的很菜鸟!

很多的毕业生,新手在初试客服的工作的时候都认为客服是很简单的事情,不过就是聊天 打字而已,对自己信心满满,但做了一段时间以后却被发现自己这么多的不懂,确实,客服 就是聊天打字,但是里面却有很多的知识是必备的,比如对产品要熟悉,对快递物流等也要 了解,对客户的聊天用语,还有就是促成定单的一些技巧也是要学会的.了解的过程可以问 老客服或者公司其他人员,譬如仓库,他们对产品也是比较熟悉的. 小强也是客服出生,刚刚开始的时候也感觉自己会打字就能做好客服的工作,真的做起来 ,很多地方会感觉自己无言以对,因为客户不知道会问什么问题,所以对产品的熟悉度是最 重要的,一个客服要了解所卖商品所有一般人能问到的问题,只要客户提问就能迅速的回 答,以提高工作的效率. 得出结论,涨工资第一步:了解产品,多学多问

当做了一段时间的客服以后,会觉得自己已经能够轻松的应对好多个客户了,这时骄傲心 就上来了,好比徒弟学了点皮毛功夫就开始炫耀自己的武功了,这时候千万不能沾沾自喜 ,要去想一下,我能同时应对5个客户了,我什么时候可以同时去面对20个客户呢?所以这时 要做的是提高,提高回复的效率,提高打字的速度,提高反映的敏锐度. 得出结论,涨工资第二步:学会突破,提高效率

终于,努力再努力,这时候其实你的工资已经涨了,因为你的效率提高了,你的业绩也就上 去了,底薪提成或者奖金相信是老板都看在眼力的,但不要认为你能同时的面对很多客户 就很NB了,谦虚是咱国人的传统,你必须谦虚,同时你要把你的经验分享给其他的同事,可 能现在要你做的是你很不情愿做的,因为这是你涨工资的秘籍,这是你靠自己的勤奋获取 的,但是如果你要想继续的涨工资,你必须这样做,虽然有可能有其他人会超越你,但你做 了,无论是同事还是老板,首先你的为人得到了肯定,说的难听点就是人品还是好的,对于 提升岗位来说,可能客服主管的位置至少离你会近一点,当然前提是你要让老板知道你给 同事分享了. 得出结论,涨工资第三步:懂得分享,提升能力

假如真的一不小心上了客服主管了,那标题写着涨工资的目标又有突破了,这时候不是悠 哉的指挥就可以了,而是要让客服的能力都提升上去,这样工作的效率才会提升,公司的业 绩才会提升,老板才会开心,或许奖金有会....... 嘿嘿,要提高客服的能力,就要先提高自己的能力,总之越高的位置,要学习的东西就越多 ,要让老板觉得给你这个待遇是值得的,当然土一点的说法就是,为了能再涨工资,继续努 力学习更多的东西,不仅仅是客服部的,很多好的建议和意见,只要对公司有利,都能提出 来,我想是老板都会去考虑的,不管有没有采纳或者实行,你提出说明你去想了,这也是进 步!还有就是一定要学会管理,因为一个部门少则两三人,多则几十个,人多了不去管理那 肯定不行,这时候自己要去把部门理顺. 得出结论,涨工资第四步:敢想敢说,学会管理
