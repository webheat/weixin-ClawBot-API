# QA·客服术语大全【精华版】 · 005 · 物流怎么还没更新？

## Q
物流怎么还没更新？

## A
亲，近段时间物流信息显示不正常是由于物流方面包裹积压，爆仓情况严重，物流方面也是查不到出仓的情况。我们已经在催快递了，快递回复说是希望卖家和买家都能耐心等等呢，他们已经在加派人员在处理爆仓积压问题了。相信您的包裹很快送到您的手里！给您带来的不便还请多担待。
