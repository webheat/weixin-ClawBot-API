# QA·最好的电商客服培训手册 · 002 · 快递丢件或商品损坏了，客

## Q
快递丢件或商品损坏了，客户来找麻烦怎么办？

## A
别慌，先稳住客户情绪。可以巧妙用表情配合话术：小失误用可爱天使表情表示无辜化解抱怨，大失误直接诚恳道歉并附上对不起表情。承认问题后给出解决方案，比如补发或退款，保持冷静随机应变，把责任推给快递只会让事情更糟。
