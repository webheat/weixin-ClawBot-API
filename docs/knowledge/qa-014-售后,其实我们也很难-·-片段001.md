# 售后,其实我们也很难 · 片段001

售后，其实我们也很难

做为服务行业，最难的就是处理售后了，涉及的部门多。而且稍不注意就会得罪客户。

前段时间给一个老客户做售后回访，客户很生气，说我把不良品返回你们公司都快大半 年了，你们一直都没有给处理。也没有一个确切的答复。到底是怎么回事，之前订货的 时候让帮忙处理，都是一直推。说是下次发货的时候给捎上，但是一直都没有。现在已 经不再相信你们公司了，你们就是一骗子公司，我现在已经选择其他的供应商了……
　　这是一个合作了多年的老客户了，若是因为售后原因没有处理好，而失去了这个客 户，那就得不偿失了。奇怪的是我在售后部并没有发现该客户的口中返所说的不良品。 而根据客户所以提供的物流单号确认是有查到那票货的。并且货运部的同事是有确实去 提过货的。可能是因为不良品堆放的时候太久都没有人处理，才会导致货不见，货毕竟 是在我们公司丢的，是我们没有给人家把货处理好，索性还好客户退回来的不良品都是 一些不怎么值钱的小东西。最后只能跟经理去申请给客户换新产品，虽然这件事最后给 客户解决了，但是拖的时间比较长，客户虽然没有催，但是他一直都记得他有一批不良 品在公司没有给他处理，至少心里留下了一下疙瘩。 
　　唯一值得庆幸的就是这个客户他还算是比较好说的话那种，虽然没有给他及时处理 好，而且是过了很长一段时间才想起了这个事。但是客户还是很配合的协助咱们的工作 ，没有让咱做业务员的为难，也把他的售后给处理了，至少心里再也不用老是想着说还 有他的售后没有处理好。
　　通过这件事我明白了一个道理：不管是大客户还是小客户，新客户还是老客户，好 说话的，不好说话的，客户有什么问题我们都要及时的去给人家处理，急客户所急，想 客户所想。
