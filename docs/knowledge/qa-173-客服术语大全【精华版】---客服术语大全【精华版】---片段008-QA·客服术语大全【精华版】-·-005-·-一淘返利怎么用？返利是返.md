# QA·客服术语大全【精华版】 · 005 · 一淘返利怎么用？返利是返

## Q
一淘返利怎么用？返利是返什么？

## A
返利返的是集分宝，100个集分宝=1元。成功通过一淘优惠购物后（交易成功的情况下），集分宝会返到您的支付宝。下次您买东西时，进入支付界面会看到“您有***个集分宝”，点击使用就能当钱用了。通过一淘搜索栏，把宝贝链接粘贴过去搜索，点击“优惠购”才能得到返利哦。
