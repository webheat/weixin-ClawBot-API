# 公司主要产品知识普及 · 片段003

 Q：什么是禁用DHCP？如何禁用？ A：禁用DHCP就是把路由器分发“门牌号”的权力削夺了，不让路由器自动分配IP，DHCP功 能可自动为每台电脑分配IP地址，不需要用户设置IP地址、子网掩码以及其他所需要的 TCP/IP参数。禁用DHCP功能也是进行无线网络加密的方式之一！禁用只需要“DHCP服务器 ”设置项下将DHCP服务器设定为“不启用”即可。 Q：路由器和交换机和HUB三者有何区别？ A：路由器、交换机、HUB（集线器）都是网络连接设备，依次向下兼容，即路由器可以 当交换机或HUB使用。路由器在三者之中最高级，具有IP自动分配功能，即带DHCP服务器 ；交换机次之，可以自动分配带宽，但不能分配IP；HUB不但不能自动分配IP，而且不能 自动分配带宽，也就是说不管同时有几台电脑在线，它都把带宽固定平均分配，现在基 本已经淘汰。 Q：如何把路由器当交换机使用呢？ A：直接在路由中禁用DHCP路由器就变成了一部交换机，此时有几个LAN口就是几口的交 换机了，WAN口不能使用，无线路由器当AP使用，同样操作！ Q：什么是AP？ A：无线AP又称为接入点/热点/网络桥接器，通俗来理解又叫无线交换机、无线HUB，是 英文AccessPoint：AP，通常一个AP能够在几十至上百米内的范围内连接多个无线用户， 在同时具有有线与无线网络的情况下，AP可以通过标准的Ethernet电缆与传统的有线网 络连接，作为无线和有线网络之间连接的桥梁。 Q：无线AP和无线路由有何区别？ A：有线接口区别：无线AP通常只有一个LAN接口，无WAN接口，只能接在有线路由器或交 换机后面，而路由器则至少有1个WAN口接口和一个LAN接口，家用路由器通常具备1个WA N口和4个LAN口接口，功能区别：无线AP不具DHCP及PPPOE拨号功能，无线路由器有DHCP 及PPPOE功能，因此无线AP通常不会直接接在不带有路由功能的MODERN（猫）上。
