# 客服专用快捷术语 · 片段007

客服快捷语录 以下就是顾客常使用的一些语句，为了提高客服的服务质量，我总结了一下，让客服自 己编辑快捷短语。现在做出来给大家分享以下： 1.顾客：店家，在吗？ 这个时候顾客也没别的意思，就跟见面说声你好一样自然，但是这就考验了一家店的服 务质量和水品。怎么样让顾客觉得受到了尊重。
      客服：亲，你好啊，很高兴为您服务，有什么可以帮助您的？ 注意一点：一开始严禁使用自动回复，这样会降低顾客的购买欲望 的。 2.顾客：可以便宜点吗？（或者有相关类似的意思） 其实顾客不是想要真的占便宜，大部分人只是由于中国讨价还价的交易习惯，随口问上 的一句，要有耐心和给予适当的优惠。顾客都会投桃报李的，这一点优惠会记在心里如 果有售后的话会比较和缓。并且可以提升成交额。

客服：亲……一分钱一分货我们的性价比是很好的呢。不过可以给亲一点小礼物呢。 3.顾客：别的地方要更便宜呢…… 其实，每个客服碰到这种买家都会很生气。这也是正常的，但是如果每个客服想想为什 么这个客人会来你这里而不是别的那里，当你找到优点时也意味着成交。

客服：亲亲，我们的商品性价比是最好的呢，看看我们的评价和销量，都是很好的呢…… （基本上顾客如果真的发现优点，就会购买，如果想要优惠，同上） 4.顾客：谢谢。 现在是文明的时代，顾客的素质也在增加，每一个人在询问完或是购物完后都会说一声 谢谢，不要小看谢谢，这有两种意思：一 顾客是个好顾客，就是我前一篇顾客分析文章中的大度温柔型，这种顾客很有成为回头 客的潜质，只要你服务到位，货品到位就会立马成为那个客服的回头客，所以，要给予 他们超出期望值的服务。也就是第二条，你的回复语言一定要体现出顾客至上的理念。

客服：不用谢，顾客就是上帝呢，呵呵（表情）。 5.顾客：亲，这个货物是什么时候发货呢？ 基本上这是每一个客户都会询问的一个问题，而我们在解答这个问题的同时也要把接下 来的一个问题解决好。比如顾客会提问大概什么时候可以到。

客服：亲，因为仓库要检查货品，所以我们承诺在48小时内发货的。并且除了内蒙古， 新疆，台湾，甘肃和黑龙江等偏远地区都在3天左右到货的，在江浙沪地区2天就可以到 ，同城今发明到的呢。（顺便要把发的物流告诉顾客，我们的是申通和韵达其余的就自 己编写一下哈） 6.顾客：亲，这个包的质量怎么样呢？ 当一个顾客这样问了，就表明顾客的购买欲望已经达到了顶点，，就差那临门一脚了， 各位客服们，想尽办法去促进成交吧。

客服：亲，我们的包包都是公司请模特的实拍呢。质量是很好的，亲可以看看评价，而 且我们有7天如有质量问题无条件退还货的完善售后体系，呵呵，亲不用担心的。 7.亲，有什么活动吗？ 这个就不多说，很简单的把自己店铺内的一下促销活动如实的反应给客户就好，比如多 少包邮，神马打折之类的，介绍给客户就行，每个店的客服都应该有的这是基本。 客服：亲，我们是满***包邮的呢。活动快截止了，亲正好赶上呢。 8.顾客：亲，这一款货……（后面的顾客就是问客服的详细属性） 这一个就要考验顾客的基本素质和素养，对于产品的了解度，对于知识的掌握，其实做 电子产品的比较悲剧，其他的就还好，无非就是询问有没有一些附送物之类的。
      客服：亲，这个东西我们是有的（或是没有），放心和实物图是一样的呢。 9.顾客：怎么半天没有理我？（指回复的时间太慢） 一般这个时候是在你做大型活动或是引流较大网速太卡的时候，这个时候就需要设置自 动回复或是使用快捷短语来熄灭顾客的怒火。
