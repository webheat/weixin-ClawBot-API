# QA·客服术语大全【精华版】 · 003 · 快递怎么还不更新？等好久

## Q
快递怎么还不更新？等好久了

## A
亲，近段时间物流信息显示不正常是由于物流方面包裹积压、爆仓严重，物流方面也查不到出仓情况。我们已经在催快递了，快递回复说希望卖家和买家都能耐心等等，他们已经在加派人员处理爆仓积压问题，相信您的包裹很快会送到您手里！给您带来的不便还请多担待。
