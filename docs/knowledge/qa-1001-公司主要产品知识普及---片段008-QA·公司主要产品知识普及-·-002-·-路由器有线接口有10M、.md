# QA·公司主要产品知识普及 · 002 · 路由器有线接口有10M、

## Q
路由器有线接口有10M、100M、1000M，选哪个够用？

## A
10M已基本淘汰，现在主流是100M和1000M。100M实际下载速度约12.5MB/s，1000M约125MB/s。普通家庭用户100M足够；如果经常拷贝大文件或做NAS存储，建议选1000M端口的路由器。
