# 公司主要产品知识普及 · 片段011

天线的主要目的就是用来加强信号的。天线增益大小一般是2DBI、4DBI、5DBI、6DB I、7DBI、10DBI、12DBI，天线的增益值越大，信号强度就越好。天线的接口有两种，分 别是SMA接口和TNC接口。SMA接口其特征为天线接头是内部螺纹，针式接头，对应的无线 网络设备端则是外部螺纹，管式接头。SMA接口的无线设备最常见，大部分的无线AP/路 由器包括无线网卡使用的都是这种接口，涉及品牌包括NetGear、D-LINK、TP- LINK等厂商产品。TNC接口要比SMA接口要粗些，它的特征为针式接头，天线接头的外部 与内部触点之间有金属屏蔽层，如CISCO和它的子品牌LINKSYS的无线设备就用这种接口 。
    如果无线设备与天线之间接口不匹配，比如说，无线设备采用SMA接口而天线采用TN C接口那么可以通过使用转接头或转接线的方式连接。（天线管式头的称为母头，针式的 称为公头）
