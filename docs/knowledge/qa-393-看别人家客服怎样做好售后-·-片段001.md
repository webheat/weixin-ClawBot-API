# 看别人家客服怎样做好售后 · 片段001

看别人家客服怎样做好售后

我们耳常常响起的总是别人家的XX，一个永远赶不上的“榜样”，但是别人家的就是比较 牛气。开网店也是一样，眼瞅着别人家的做得那么轻松，今天，运维创意带大家一起来 分享下优秀的淘宝客服是怎样处理常见的问题的。

优秀的客服，不仅需要快速处理问题的的能力，而且还能让买家满意给店铺好评，甚至 有可能成为店铺的老客户。关于售后的处理问题：

1丶退换货

当顾客要求退换货的时候，一般比较好讲的顾客要是个人原因，通常都是会比较自主的 承担这个费用，而我们就需要把该顾客的ID号登陆到销售表格去，是由于什么原因退货 的，谁承担的这个费用，还有其退回来的物流单号。因为这个物流单号是查看她退回来 的包裹我们仓库是否已签收，仓库收到的包裹无法辨别是哪个顾客的时候，我们就可以 通过这个物流单号来查找。

要是碰到一些比较难缠的顾客，自己不适合的码数或者不喜欢等各种原因，都是会找一 堆借口来要求我们承担这个退货的运费，此时就是有理也是讲不通的，顾客甚至还会要 求小二来介入处理这个问题。那这样要求小二介入处理的话，只会增加我们的退款纠纷 ，而这个对店铺的影响也会很大的，所以只能做退让，比如一人承担一半的运费。还有 是需要处理顾客的退货申请，如果是个人原因的话，一般只能申请七天无理由退换货， 这样对我们的店铺不会有影响，如果申请的是其它理由的话，则就需要看一下聊天记录 了，看他为什么要申请这个退款原因，如果与实际中的不符合，都是需要拒绝，价格不 正确的，也要委婉拒绝的。

2丶退款

再来就是看退款的时候，有一些顾客订单中有购买的运费险，就是申请退货后，我们同 意了她的退货申请，她需要在订单中填写上退货的物流单号，而这个单号填写上后，就 会有一个退款的倒计时，一般会有9天的时间，如果只剩下5天左右还未有物流的时候， 要先点击拒绝！不然的话系统会自动退款。如果购买了运费险，没有填写上物流单号的 ，我们收到她退回来的货，要给她退款，也是退不到的，还是需要填写上单号，才会退 款，时间到了没有填写的话，就会自动关闭退款申请。

要是换货的话，是需要顾客来承担来回运费，也就是退回的运费，还有换货我们发出的 运费，确认好之后还需要登记在换货表格里面，要求顾客先补回一个相对应的运费价格 ，然后再给回地址退回处理换发。

如果是需要退款的，一般在20元以下的，可以登记到退款表格，写明支付宝退款原因， 写上价格，确认可以退的话直接备注标红色字体，主管/财务看到就会直接退款。

3丶做好仓库的沟通和快递沟通

每天早上上班的时候，都需要打开共享表格里面看看，因为会有晚班登记下来需要我们 早班同事处理的问题，由于晚上仓库没有上班，所以没有办法在第一时间处理。比如一 些漏发的丶没有物流的丶催货的丶咨询仓库的等都是需要登记一个表格，然后统一发过 给处理。有些顾客是比较急，而仓库回复的话比较慢，都会找一下理由让顾客再等等， 回复了会及时留言等。

与快递联系的话，也是使用QQ，需要修改地址，或者需要问包裹重量，退回哪个单号包 裹，修改地址：都是需要发物流单号，确认顾客的原地址，然后再发修改的地址，一起 发给快递客服进行修改。追回包裹的，也是一样订单号与顾客的地址！如果QQ上快递没 有回复的，那就只能打电话。

甚至仓库那边有时候会发一些问题 ，顾客拍下的时候没有选择码数，或者地址不到的，都需要我们客服打电话去咨询确认 码数，或者咨询哪一个物流可以到达。
