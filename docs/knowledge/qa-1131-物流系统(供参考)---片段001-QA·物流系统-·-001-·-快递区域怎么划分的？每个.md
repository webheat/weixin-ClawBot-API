# QA·物流系统 · 001 · 快递区域怎么划分的？每个

## Q
快递区域怎么划分的？每个区包含哪些地方？

## A
快递分为四个区域。一区(3个)：上海、浙江、江苏。二区(22个)：黑吉辽、京津冀、山西、山东、河南、安徽、四川、重庆、湖北、贵州、湖南、江西、福建、云南、广东、广西、海南。三区(6个)：内蒙古、甘肃、新疆、西藏、青海、宁夏。特殊区域(3个)：香港、澳门、台湾。
