# 淘宝网总概(买家入门) · 片段002

付款成功后，您可以再次进入“我的淘宝”—“我是买家”—“已买到的宝贝”页面查看交易 ，此时交易状态为“买家已付款”，等待卖家发货即可：
    [pic]

您也可以登录支付宝网站，点击首页右侧的“交易管理”，进入“消费记录”页面，找到 对应交易，点击“付款”即可：
   [pic]
   付款方式介绍：
   1、当您的支付宝账户余额足够支付所拍宝贝的订单金额，您可以直接使用支付宝余 额支付，输入支付宝账户支付密码，点击“确认付款”即可：
   [pic]

当您的支付宝账户余额不够支付所拍宝贝的订单金额，您可以先将已有的支付宝余额 勾选使用，剩余金额用其他方式支付，或不勾选支付宝余额付款，全部订单金额直接选 择用其他方式支付：
   [pic]

储蓄卡支付
   若您的支付宝账户没有余额或余额不足，而您拥有支付宝卡通或已开通网上银行的借 记卡，您可以选择全部订单金额用“储蓄卡”支付或剩余订单金额用“储蓄卡”支付，选择 “银行卡对应的银行名称”，点击“下一步”：
   [pic]

若选择有误，可点击下方的“选择其他方式付款”重新选择，确认选择无误后，点击“ 登录到网上银行付款”即可进入网上银行支付页面：
   [pic]

信用卡支付
   若您的支付宝账户没有余额或余额不足，而您拥有具备信用卡功能的支付宝卡通或已 开通网上银行的信用卡，您可以选择全部订单金额用“信用卡”支付或剩余订单金额用“信 用卡”支付，选择“银行卡对应的银行名称”，点击“下一步”：
    [pic]

若选择有误，可点击下方的“选择其他方式付款”重新选择，确认选择无误后，点击“ 登录到网上银行付款”即可进入信用卡网上银行支付页面：
   [pic]

找人代付 找人代付是指当您在网上购买商品后，可以由别人帮您完成网上付款。 
注意：淘宝购物车多笔付款不支持代付 1、在淘宝网上拍下商品，在确认购买信息的页面，点击“找人代付付”[pic] 2、单笔的淘宝购物车交易可以用“找人代付”（在淘宝页面除这两个入口外就没有其他“ 找人代付”的入口了） [pic] 3、如果确认购买时没有选择“找人代付”或者页面关闭后，客户又想找人代付了，“找人 代付”入口在支付宝消费记录，点击“商品名称”进去后操作。

[pic] 4、以个人体验版为例：点击“商品名称”后跳出一个对话框： [pic]

5、点击“找人代付”（收货地址显示给代付人可勾选，勾选后，代付人可以看到买家的收 货地址） [pic] 6、可以选择“指定人代付”和“任何人都可以代付”二种方式： 1）指定人代付的操作方式： 
[pic] 输入正常的可以登录的支付宝账户，提示代付设置成功。 [pic]

2）任何人都可以代付的操作 点击“任何人都可以代付”，复制“获取代付链接”发给好友 [pic] 如果代付人表示没有收到“代付的链接”，买家可以进入交易管理（或者消费记录），点 击“查看代付链接”，把此链接发给代付人进行代付的操作。 [pic]
