# QA·详细的客服 · 001 · 客服有什么考核标准吗？

## Q
客服有什么考核标准吗？

## A
客服有严格KPI考核，包括加分项和扣分项。加分项有：工作量质量第一、无违规、满分考试、主动顶班、完成额外工作、有效投诉为零、合理化建议等。扣分项涉及：未用普通话、桌面凌乱、卫生未做、迟到早退、交接记录不完整、回复不耐心、离岗超5分钟、工作执行不力、闲聊、大声喧哗、办公区吃东西、信息录错等。
