# QA·更新 · 001 · 客服老半天才回复我一句'

## Q
客服老半天才回复我一句'恩'，买衣服问了半天都不理人是怎么回事？

## A
回复太慢是服务大忌！买家等太久早就跑了。别觉得忙，机会难得，淘宝店铺最忌讳这种敷衍。正确做法：看到消息马上回复，开口先说“您好呀，有什么能为您效劳的吗”，让买家感觉被重视，哪怕不买都觉得不好意思。回复速度就是金钱，旺旺响铃三声内必须响应。
