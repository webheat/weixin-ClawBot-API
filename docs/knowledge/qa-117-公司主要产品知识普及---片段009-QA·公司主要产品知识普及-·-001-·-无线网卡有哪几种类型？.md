# QA·公司主要产品知识普及 · 001 · 无线网卡有哪几种类型？

## Q
无线网卡有哪几种类型？

## A
按连接形式分广域网和局域网，广域网有GPRS/EDGE、CDMA、3G的TSCDMA，局域网主要是802.11ABGN标准。按接口分外置网卡（PCMICA、PCMICA EXPRESS、USB）和内置网卡（PCI台式机、MINIPCI、PCI-E笔记本）。
