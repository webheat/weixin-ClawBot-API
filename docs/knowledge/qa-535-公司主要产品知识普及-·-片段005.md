# 公司主要产品知识普及 · 片段005

 接入方法2:小区宽带(FTTX+LAN) 这是大中城市目前较普及的一种宽带接入方式，网络服务商采用光纤接入到楼（FTTB） 或小区（FTTZ），再通过网线接入用户家，为整幢楼或小区提供共享带宽（通常是10Mb /s）。目前国内有多家公司提供此类宽带接入方式，如网通、长城宽带、联通和电信等 。 入方法3:有线通 有的地方也称为“广电通”，这是与前面两种完全不同的方式，它直接利用现有的有线电 视网络，并稍加改造，便可利用闭路线缆的一个频道进行数据传送，而不影响原有的有 线电视信号传送，其理论传输速率可达到上行10Mbps、下行40Mbps。 Q：什么是MAC地址及MAC地址克隆、MAC地址过滤？ A：Mac地址就是在媒体接入层上使用的地址，通俗点说就是网卡的物理地址，在网络中 查找网卡的存在都是依靠这个地址进行的，现在的Mac地址一般都采用6字节48bit（在早 期还有2字节16bit的Mac地址），每个路由器和网卡都有唯一的MAC地址。网络运营商为 防止用户申请一条宽带线路多用户上网，网络运营商可能对每条宽带线路与一个MAC地址 进行绑定，运营商指定的网卡的MAC地址复制到路由器上，就叫MAC地址克隆，解决运营 商的限制，实现多台电脑通过路由共享上网。MAC地址过滤，路由器把允许接入网卡的M AC地址加入到列表中，未被加入列表的地址无法实现上网，就是MAC地址过滤，是路由器 加密的一种手段之一！ Q：无线路由器的加密方式主要有哪几种呢？ A：　主要有以下三种：一是设置网络密钥，包括WEP和WPA模式，64位和128位的加密类 型，分别输入10个或26个字符串作为加密密码；二是禁用SSID广播，SSID就是你给自己 的无线网络所取的名字，在无线路由器中勾选“禁止SSID广播，无线网络可以用，但在其 它人的搜索列表中就不出现，是一种比较初级简单的加密方式；三是禁用DHCP，即禁止 无线路由器的DHCP为接入的电脑分配IP，无法获得IP且无法知道无线路由器的IP就无法 上网；四是启用MAC地址、IP地址过滤，所需要接入的计算机的MAC地址或预先设定的IP 地址都输入IP地址允许列表中，未被列入允许列表中则无法访问无线路由器或通过无线 路由器上网。
