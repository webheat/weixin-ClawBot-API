# QA·公司主要产品知识普及 · 001 · 路由器、交换机、HUB有

## Q
路由器、交换机、HUB有什么区别？

## A
路由器、交换机、HUB都是网络连接设备，从高级到低级依次是路由器>交换机>HUB。路由器最高级，带DHCP功能能自动分配IP；交换机次之，能自动分配带宽但不能分配IP；HUB最弱，不管几台电脑在线都固定平均分配带宽，现在基本淘汰。路由器可以当交换机或HUB用。
